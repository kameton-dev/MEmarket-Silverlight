**MEmarket Silverlight** — это новый клиент магазин приложений Millennium Market для Windows Phone 8.1, работающий на основе простых JSON-репозиториев, которые могут создавать абсолютно все, тем самым распространяя больше приложений. Замена MEmarket на WinRT

> [!IMPORTANT]
> Приложение сейчас находится в стадии **активной разработки**. Будьте готовы к частым обновлениям и возможным ошибкам

---

## О Millennium Market
Этот проект делает упор на **открытый исходный код и поддержку сообщества**. **Каждый** может создать свой собственный репозиторий и разместить его на своём сервере либо захостить через GitHub Pages (как пример). Он **не** несет никакой корпоративной цели и **не** зависит от одного сервера, это означает что проект будет жив вместе с сообществом.

## Особенности:

- **Каноничный дизайн** — интерфейс более приближенный к Windows Phone Store.
- **Репозитории** — поддержка нескольких репозиториев одновременно и их управление.
- **Кроссплатформенность** — поддержка приложений под Windows Phone 8.1 и Windows 10 Mobile.
- **Простота** — репозитории хранятся в простом JSON-формате, легко генерируются и обновляются.

## Быстрый старт

### Предварительные требования 
- Visual Studio 2013/2015.
- Устройство на Windows Phone 8.1.

### 1. Клонирование репозитория
```bash
git clone https://github.com/kameton-dev/MEmarket-Silverlight.git
```
### 2. Сборка проекта
- Откройте решение MEmarket.sln в Visual Studio
- Выберите целевую платформу ARM
- Собрать и запустить приложение через VS
