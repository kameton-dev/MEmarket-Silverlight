**MEmarket Silverlight** is a client for the decentralized Millennium Market app store for Windows Phone 8.1, supporting direct device deployment.

> [!IMPORTANT]
> The app is currently in **active development**. Please be prepared for frequent updates and possible bugs.

---

## About Millennium Market

**Millennium Market (MEmarket)** is a decentralized app store system. It includes an official repository of verified and essential apps (MEmarket-Basic), as well as a set of tools for customizing and conveniently working with the store. The project was created and is still being developed by one enthusiast, thanks to the support of our small but close-knit community. MEmarket's main goal is to prove that this approach doesn't have to be complicated and accessible only to geeks. It is a platform that is as user-friendly and intuitive as possible for every user.

## Features:

- **Canonical design** – an interface more closely aligned with the Windows Phone Store.
- **Full-featured app installation** — deploy apps to your device with a single click!
- **Repositories** — support and manage multiple repositories simultaneously.
- **Downloads and Updates** — manage and update installed packages.
- **Simplicity** — repositories are stored in a simple JSON format and are easy to generate and update.

## Quick Start

### Prerequisites
- Visual Studio 2013/2015.
- Windows Phone 8.1 device with:
1. Interop and Developer Unlock
2. CMD Injector installed and injected

### 1. Clone the repository
```bash
git clone https://github.com/kameton-dev/MEmarket-Silverlight.git
```
### 2. Build the project
- Open the MEmarket.sln solution in Visual Studio
- Select the target platform as ARM
- Restore NuGet packages
- Build and run the application via VS

...or simply download the [ready-made .xap file](https://github.com/kameton-dev/MEmarket-Silverlight/releases/latest)
