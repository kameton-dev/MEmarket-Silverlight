## О Millennium Market

**Millennium Market (MEmarket)** — это децентрализованная система магазина приложений. В нее входит официальный репозиторий проверенных и самых необходимых приложений (MEmarket-Basic), а также комплект инструментов для настройки и комфортной работы с магазином. Проект был создан и по сей день развивается одним энтузиастом благодаря поддержке нашего небольшого, но дружного сообщества. Главная цель MEmarket — доказать, что такой подход не обязательно должен быть сложным и доступным только «для гиков». Это платформа, которая максимально дружелюбна и понятна для каждого пользователя.

## Особенности:

- **Каноничный дизайн** — интерфейс более приближенный к Windows Phone Store.
- **Полноценная установка приложений** — приложения могут быть развернуты на вашем устройстве в один клик!
- **Репозитории** — поддержка нескольких репозиториев одновременно и их управление.
- **Загрузки и обновления** — управление установленными пакетами и их обновление.
- **Простота** — репозитории хранятся в простом JSON-формате, легко генерируются и обновляются.

## Быстрый старт

### Предварительные требования 
- Visual Studio 2013/2015.
- Устройство на Windows Phone 8.1 c:
  1. Interop и Developer unlock
  2. Установленным и инжектным CMD Injector

### 1. Клонирование репозитория
```bash
git clone https://github.com/kameton-dev/MEmarket-Silverlight.git
```
### 2. Сборка проекта
- Откройте решение MEmarket.sln в Visual Studio
- Выберите целевую платформу именно ARM
- Восстановите пакеты NuGet
- Соберите и запустите приложение через VS

...ну либо просто скачайте [готовый .xap файл](https://github.com/kameton-dev/MEmarket-Silverlight/releases/latest)
